HOW TO USE ❤️

1. Keep every file in this folder together.
2. Open index.html in Chrome to preview the surprise.
3. To make it a shareable link, upload the folder to a static hosting service such as GitHub Pages.
4. The video is included locally, so it will play from the hosted page.
